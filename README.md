# S&P 500 Forward P/E Valuation Bands

Interactive S&P 500 valuation bands for GitHub Pages. The chart plots SPX against next-twelve-month EPS multiplied by 18x through 23x P/E multiples.

## Data

The static dataset is generated by `scripts/update-data.mjs` from the StreetStats daily valuation API:

- `SPX`: S&P 500 index level
- `eps`: next-twelve-month S&P 500 operating earnings estimate
- `pe`: forward 12-month P/E

Formula:

```txt
band level = NTM EPS estimate * P/E multiple
```

The committed dataset lives at `src/data/valuation-data.json`. GitHub Actions refreshes it during each Pages deployment.

## Local Development

```bash
npm install
npm run update-data
npm run dev
```

## Checks

```bash
npm run lint
npm run build
```

## Deployment

The workflow at `.github/workflows/pages.yml` builds and deploys the site to GitHub Pages on pushes to `main`, manual dispatch, and scheduled weekday refreshes.
